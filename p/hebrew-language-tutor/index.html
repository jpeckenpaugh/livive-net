English / Hebrew Language Tutor

experiment

Study, quiz, and exam modes for English-Hebrew vocabulary

About

A simple web application for learning English <-> Hebrew vocabulary. It ships five seeded lessons (10 vocab items each) with study, quiz, and exam modes, persists quiz/exam attempts as per-lesson score history, and includes a dummy-gated admin area for adding and editing lessons and vocabulary. The frontend is a plain HTML/CSS/JS single-page app using locally hosted Bootstrap 5.3.3, and the backend is a FastAPI service backed by SQLite, which serves the SPA and owns all application state. The repository contains two experiments: the primary client/server app built via a 9-stage decomposed role pipeline, and a single-pass static SPA proof-of-concept with hardcoded vocabulary under proof-of-concept/. README status is PASS based on a curl-driven API verification and static frontend review; known limitations include a dummy admin gate and in-memory tokens that don't survive restarts.
