Roblox API Database

active

Git-tracked Roblox Client and Studio API dumps for offline schema lookup

About

Roblox API Database is a versioned, git-tracked collection of official Roblox Client and Studio API dumps fetched from Roblox CDN endpoints. It stores timestamped JSON API snapshots under versions/ with a current/ symlink to the latest dump, and ships lightweight self-contained Python CLI tools (query_api.py, validate_api.py, fetch_api_dump.sh) for looking up enums, classes, inheritance, properties, methods, and events without reading the multi-megabyte dump directly. It is designed for offline engine schema lookup, static analysis, and programmatic validation in CI/CD pipelines, and can be added to projects as a git submodule. Only Python 3.x and the standard library are required; a unittest suite and valid/invalid Lua sample folders support testing.
