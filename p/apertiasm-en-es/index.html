apertiasm-en-es

experiment

Experimental WASM build of Apertium for English to Spanish translation

About

apertiasm-en-es packages the Apertium rule-based machine translation engine and the apertium-eng-spa language pair as WebAssembly for in-browser English-to-Spanish translation. The project is organized in stages: Stage 2 establishes a reproducible Emscripten toolchain producing apertium.js and apertium.wasm; Stage 3 fetches and packages the eng-spa language data with smoke-phrase validation; Stage 4 builds a framework-free standalone HTML/JS/CSS demo with an English input area, translate button, Spanish output, and runtime milestone panel; Stage 5 wires the real runtime command pipeline (lt-proc, apertium-tagger, apertium-pretransfer, apertium-transfer, and transfer preprocessing) in browser Web Workers; and Stage 5c emits a single direct WASM runtime module (apertium-runtime.js/wasm) exporting runtime status and translate_en_es. The demo attempts the direct runtime first, then the command runtime, then falls back to a Stage 2 bridge, with a Stage 2b probe attempting a full libxml2/lttoolbox/apertium-core WASM build.

Summary

An experimental WebAssembly build of the Apertium machine translation engine with the English/Spanish (eng-spa) language pair packaged for browser use.
