About

Lokarta: Come Into The Light is a retro-inspired, grid-based 2D roguelike RPG. The project exists as four iterations of the same game: the original lokarta is a local-first Python terminal proof of concept for a BBS-style ASCII RPG (fixed 100x30 screen, JSON-driven content packs, single-key input, engine/UI separation); lokarta-v2 is a browser edition built with TypeScript and Vite, rendered on an HTML5 2D Canvas with a companion FastAPI + SQLite backend for dungeon layout, loot seeding, and character state; lokarta-v3 rebuilds the game as a zero-backend, client-side application using native web standards (ES modules, Web Workers, Canvas 2D, Web Audio API, IndexedDB) with four vocations, a five-tier tower ascent, and a Havenreach town hub; lokarta-v4 is the most complete engine, adding a Dawnreach Isle overworld, an island quest chain, NPC actors, expanded sprite direction sets, and more Web Worker RPC handlers and data catalogs. Gameplay pillars include a light-versus-darkness mechanic where pitch-black chambers are only revealed within a torch or spell light radius, frictionless walkover auto-loot, a roguelike Fate Grant draft on level-up, and multi-modal inputs (tap, hold/charge, double-tap).

Summary

A zero-backend, client-side 2D roguelike RPG with a real-time 10 Hz tick, dynamic light-and-darkness line-of-sight, and four playable vocations, evolved across four repositories from a Python terminal prototype to a native browser game.
