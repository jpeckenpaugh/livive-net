Open Code Workflows

active

Role-based agent pipelines that turn a seed concept into a web app

About

Open Code Workflows is a reusable set of role-based pipelines for building web apps with an agentic coding assistant. Given a short seed concept, the workflows drive a staged build with human checkpoints through clearly separated roles: concept (human-supplied), feature decomposition, feature briefs, system engineering, architecture, backend, frontend, verification, and documentation. Three pipelines are provided: build (stages 01-09), enhancements (stages 01-10), and debug (stages 01-03). A meta Stage Manager role sequences, dispatches, gates, and audits each stage, spawning and resuming sub-agents per role. The repo includes ready-made seed concepts such as a language tutor, job tracker, client project tracker, sales/inventory tracker, plant nursery, and capstone project tracker. Each generation follows a fixed artifact chain (concept to features to briefs to env scripts to architecture to backend to frontend to verification to README); stages commit and push as their final step. It was designed and validated in OpenCode with DeepSeek V4 Flash but is model- and agent-agnostic, written as plain Markdown instructions.

Summary

Reusable Markdown-defined agent pipelines (build, enhancements, debug) that drive a staged, human-checkpointed build of a web app from a seed concept via stage-managed sub-agents.
