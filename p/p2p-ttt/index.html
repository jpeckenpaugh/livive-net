About

Act III of the Tic-Tac-Toe Architecture Trilogy eliminates the backend server entirely. Two browsers pair by exchanging Deflate-compressed URL hashes or scanning full-screen QR codes, stream live moves directly peer-to-peer over WebRTC DataChannels with zero relay server, and persist full replayable match histories inside each browser's local WebAssembly SQLite (sql.js) database backed by the Origin Private File System (OPFS).

Summary
