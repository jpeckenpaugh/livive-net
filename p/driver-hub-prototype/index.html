Driver Hub Prototype

prototype

Uber-style ride-hailing prototype connecting drivers and passengers in real time

About

Driver Hub Prototype is a functional, modern prototype of a ride-sharing platform connecting Drivers and Passengers in real time. It demonstrates the essential passenger-driver interaction: requesting a trip on an interactive map, real-time notification and acceptance by the driver, visual route tracking, and reactive trip status updates. The interface is designed for side-by-side demos (split screen or two devices). The stack is React 19 + TypeScript + Vite + Tailwind CSS on the frontend, Leaflet / React-Leaflet with OpenStreetMap for maps (no API keys needed), and Node.js + Express + Socket.io for real-time communication across browsers or devices on the same local network. The repository is an npm workspaces monorepo with shared, server, and client packages, and GitHub Pages workflows for deployment.

Summary

A lightweight full-stack prototype of a ride-hailing platform (Uber/Cabify style) that pairs drivers and passengers in real time over an interactive map.
