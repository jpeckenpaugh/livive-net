Company Hub

prototype

Internal web app to view and maintain company profiles

About

Company Hub is a self-contained internal web app for a small, globally distributed firm to view and maintain information about the companies it works with. It distinguishes structured company data (stored in a relational database) from files and generated artifacts (stored as object-like files on disk), and is meant as a lightweight backbone for other internal workflows rather than a full CRM. Features include browsing and searching companies, country filtering, editable company profiles, standardized industries and locations, per-company references, news and logos, file/artifact upload and download, and one-page PDF summary generation. Sprint 03 added role-based access (guest, read-only, user, admin), admin user management, and optional Google SSO. The backend is FastAPI on async SQLAlchemy 2.0 with SQLite and versioned Alembic migrations, auth via fastapi-users with cookie sessions, and a static Bootstrap SPA frontend served by the app. It also ships OpenCode tools and agents that use the same authenticated API.

Summary

A lightweight internal web app for a small firm to browse, view and edit profiles of the companies it works with, manage related files, and generate PDF summaries.
