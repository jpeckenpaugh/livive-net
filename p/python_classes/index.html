Python Classes Demo

prototype

Progressive Python OOP demos with a food domain: inheritance and composition.

About

Python Classes Demo is a small, progressive demonstration of Python object-oriented programming built around a food-themed domain. Base classes and subclasses are defined in food.py (Food with Fruit, Meat, and Beverage) and person.py (Person with Vegetarian), while meal.py illustrates composition through a Meal that contains multiple Food items. The examples show inheritance and method overriding (Fruit.eat, Meat.eat, Beverage.drink), composition, polymorphism, and state and validation held inside methods. Simple domain rules are modeled, including mandatory hand-washing before eating or drinking, requiring fruit to be washed and ripe and meat to be cooked before eating, vegetarian restrictions, allergies, a one-fruit limit for diabetics, an age 21+ check for alcoholic beverages, and people only becoming full at the end of a meal. Eight numbered example scripts progress from a minimal Person and Food case (example01.py) through cooking, washing/ripening, allergies and dietary limits, beverages, and a full Meal demo (example.py). Each example runs directly with python example01.py, and no manifest or third-party dependencies are present.

Summary

A small, progressive set of Python examples demonstrating classes, inheritance, composition, polymorphism, and simple stateful business rules using a food-themed domain.
